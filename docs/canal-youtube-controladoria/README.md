# Projeto: Canal YouTube — Controladoria Estratégica

Backlog completo para o lançamento de um canal no YouTube sobre controladoria estratégica, estruturado no padrão PMO (Charter → WBS → Épicos → Issues → Roadmap → KPIs → Riscos).

| Arquivo | Conteúdo |
|---|---|
| [`00-BACKLOG.md`](./00-BACKLOG.md) | Project Charter, posicionamento, roadmap, épicos, matriz de priorização, KPIs, riscos, fluxo de trabalho, calendário editorial e orçamento |
| [`01-ISSUES.md`](./01-ISSUES.md) | As 80 issues detalhadas, com tipo, prioridade, estimativa, sprint, dependências, responsável e critérios de aceite |
| [`issues.csv`](./issues.csv) | Mesma lista em formato importável para Asana, ClickUp, Jira, Trello ou GitHub Issues |

## Números do projeto

- **80 issues** em **10 épicos** e **6 sprints**
- **269 horas** de esforço estimado
- **42 issues Must have** (141h) bloqueiam o lançamento
- Janela planejada: **24/08/2026 → 31/12/2026** · estreia pública em **06/10/2026**

## Como importar o CSV

**Asana** — Projeto → ⋯ → Importar → CSV. Mapear: `Titulo`→Nome, `Criterios_de_aceite`→Descrição, `Responsavel`→Responsável, `Prioridade`→campo customizado, `Sprint`→Seção.

**ClickUp** — Espaço → ⋯ → Importar → CSV. Mapear `Sprint` para Lista e `Epico` para tag.

**GitHub Issues** — usar `Epico` e `Tipo` como labels e `Sprint` como milestone.

O arquivo está em UTF-8 com BOM, para abrir corretamente no Excel em português.
